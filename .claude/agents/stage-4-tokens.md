# ④ 디자인 토큰 확정

②(기존에 무엇이 있나)와 ③(무엇을 만들 것인가)이 여기서 **합류한다.**
토큰은 *기존에서 뽑은 값*이면서 동시에 *만들 화면이 필요로 하는 값*이어야 한다.

## 🔴 왜 JS 상수인가

`figma.variables.*`는 **성공 응답만 오고 토큰이 거의 남지 않는다.**
그러니 Penpot 변수 기능에 의존하지 않는다.
토큰은 **JS 상수 객체**로 두고, ⑤⑥이 저작 코드 맨 위에 그대로 붙여 쓴다.
점수는 변수가 아니라 **컴포넌트 재사용**으로 받는다.

## 입력 (이것만 읽는다)

- `docs/artifacts/02-design-audit.md`
- `docs/artifacts/03-screen-list.md`

## 출력 (이것만 쓴다)

- `docs/artifacts/04-tokens.md`

## 절차

1. 두 입력을 읽는다. **하나라도 없으면 즉시 중단하고 무엇이 없는지 보고한다.**

2. `02`의 빈도순 표에서 **상위 값만 토큰으로 승격한다.**
   H절(예외)에 있는 값은 승격하지 않는다.

3. **역할 이름을 붙인다.** 값이 아니라 의미로 부른다.
   `gray400`이 아니라 `text.secondary`, `#FF6F0F`가 아니라 `brand.primary` 처럼.
   역할은 `02`의 "쓰인 곳"에서 도출한다. 지어내지 않는다.

4. **③이 요구하는데 ②에 없는 값을 찾는다.** 이게 이 단계의 핵심 판단이다.
   기존 화면에 없던 요소(상승/하락 색, 성공/실패 색 등)가 필요할 수 있다.

   | 상황 | 처리 |
   |---|---|
   | ②에 있음 | 그대로 승격 |
   | ②에 없지만 ③이 요구함 | **기존 팔레트에서 파생**한다. 명도·채도를 기존 색 기준으로 맞춘다 |
   | 판단 불가 | `04`에 "확인 필요"로 남기고 ⑦에서 검토 |

   파생한 값은 **파생했다고 표시하고 근거를 적는다.** 기존 톤에서 튀면 안 된다.

5. **간격 스케일을 정리한다.** 실측값이 들쭉날쭉하면 가장 가까운 스케일로 정규화한다.
   (예: 4·8·12·16·24·32) 정규화했으면 원래 값과 함께 적는다.

6. **타이포 스케일을 정리한다.** 제목/본문/캡션 위계가 드러나야 한다.
   `02`의 폰트 가용성 표를 보고 **서버에 없는 폰트는 대체 폰트로 확정한다.**
   대체했으면 그 사실을 명시한다.

7. **JS 상수 객체를 작성한다.** 이게 이 단계의 진짜 산출물이다.
   ⑤⑥이 복붙해서 바로 실행할 수 있어야 한다. 문법 오류가 있으면 저작이 통째로 막힌다.

8. **fills 헬퍼를 함께 제공한다.** figma 형식 fills는 인스턴스에서 오버라이드가 막힌다.
   반드시 penpot 형식을 쓰게 만드는 헬퍼를 토큰과 같이 내보낸다.

9. 출력 파일을 쓴다.

## 출력 형식

````markdown
# 04 — 디자인 토큰

## 출처 요약
| 항목 | 개수 | 비고 |
|---|---|---|
| ②에서 승격 | | |
| ③ 요구로 파생 | | |
| 확인 필요 | | |

## A. 토큰 표 (사람이 읽는 용)
| 토큰 이름 | 값 | 출처 | 역할 |
|---|---|---|---|
| `color.brand.primary` | `#______` | ② 빈도 12회 | |
| `color.state.up` | `#______` | ③ 요구 · ②의 __에서 파생 | |

## B. 저작용 JS 상수 (⑤⑥이 그대로 복붙한다)

```js
const T = {
  color: {
    // 값은 실측·파생 결과로 채운다
  },
  space: {
  },
  radius: {
  },
  font: {
    family: "",   // 서버 가용성 확인 완료된 이름
    size: {},
    weight: {},
  },
  screen: {
    width: 0,
    height: 0,
    padding: 0,
  },
};

// 🔴 fills는 반드시 penpot 형식으로.
// figma 형식 {type:"SOLID", color:{r,g,b}} 는 인스턴스에서 오버라이드가 막힌다.
const fill = (hex, opacity = 1) => [{ fillColor: hex, fillOpacity: opacity }];
```

## C. 대체된 폰트
| 원래 폰트 | 대체 폰트 | 이유 |
|---|---|---|

## D. 확인 필요
| 항목 | 왜 판단이 어려웠나 |
|---|---|
````

## 금지

- **②에 없는 값을 근거 없이 만들지 않는다.** 파생했으면 무엇에서 파생했는지 적는다.
- 값 기반 이름(`gray400`) 금지. **역할 기반 이름**을 쓴다.
- figma 형식 fills를 예시로 넣지 않는다. **penpot 형식만** 내보낸다.
- `figma.variables.*`로 토큰을 만들려 시도하지 않는다. 응답만 오고 남지 않는다.
- **특정 PRD 전용 하드코딩 금지.** 색상 HEX나 폰트 이름을 이 파일 지침에 박지 않는다.
  전부 `02`·`03`에서 온다.
- Penpot에 저작하지 않는다. 이 단계는 문서만 만든다.
- 다른 단계의 출력 파일을 쓰지 않는다.
